北通手柄 → Xbox 360 映射器
================================

这东西干什么
------------
北通 BTP-V1T（腾讯先游定制版，VID 20BC / PID 503C）在电脑上只有 BFM 安卓模式，
走的是 Dinput 协议。基岩版 Minecraft 这类只认 XInput 的游戏压根看不到它。

这个程序直接读手柄的 HID 原始报告，然后在系统里造一个真实的 Xbox 360 手柄，
游戏看到的就是标准 XInput 手柄，100% 认。不用改手柄模式，也不用装北通驱动。

怎么用
------
如果是用安装包装的：开始菜单 → 北通手柄映射器。
程序装在 %LOCALAPPDATA%\Programs\BetopMapper（免管理员权限，键位文件可写），
卸载走开始菜单里的「卸载 北通手柄映射器」，或控制面板的程序列表。

绿色版就直接双击 BetopXboxMapper.exe。

1. 双击 BetopXboxMapper.exe（第一次打开会自动弹「📖 新手教程」，七步图解）
2. 点界面上的「启动映射」
3. 状态栏显示"运行中"就可以开游戏了
4. 关窗口会缩到右下角托盘里继续跑（不是退出）；
   要彻底退出：右键托盘图标 → 退出程序

完整流程看左侧「📖 新手教程」：装驱动 → 插手柄 → 跑键位向导 → 启动映射 →
游戏里选控制器 → 调震动。每步都有图，还能当场检测驱动和手柄接好没。

手柄要用 USB 线连着（蓝牙模式不行）。

界面与多开（v1.0.31）
----------------------
界面按系统缩放自动适配：屏幕开了 125% / 150% 缩放的话，文字和窗口都是正常
大小，不会再出现「字小得可怜」的情况。窗口还能随便拉大拉小，手柄图跟着缩放。

嫌字小或字大：左侧「界面大小」滑块，80% ~ 200% 随便拖，松手就存，
点旁边的「↻ 重启生效」（或直接重启程序）即可。拖到跟系统一致的值会显示
「（自动）」，此时跟着屏幕缩放走，换机器也不用重调。

程序只允许同时开一个：已经开着的时候再双击图标，只会把旧窗口翻到前台，
不会再新开一个。要彻底退出：右键托盘图标 → 退出程序。

文件说明
--------
BetopXboxMapper.exe   主程序，双击这个
BetopWizard.exe       键位识别向导（换手柄或键位乱了才用）
keymap.json           键位配置。改完键记得点界面上的「保存」，就写在这个文件里
ViGEmBus_Setup.exe    ViGEmBus 驱动安装包，只有换电脑才需要装

换到别的电脑上用
----------------
1. 先装 ViGEmBus_Setup.exe（必须，不然造不出虚拟 Xbox 手柄）
2. 再双击 BetopXboxMapper.exe

本机已经装过 ViGEmBus 了，不用再装。

键位不对怎么办
--------------
界面上每个按键下面有个「改」按钮：先点「启动映射」，再点某个键的「改」，
然后按住手柄上你想当这个键用的那个键，几秒就绑好了，最后点「保存」。

摇杆漂移：拖动界面上的「摇杆死区」滑块往大调。
摇杆方向反了：对应轴后面点「反向」。

FN 键
------
FN 是摆设，别指望它。它是纯硬件键，按下去手柄不往 USB 发任何东西
（报告字节一个都不变），所以既映射不了也当不了修饰键。
界面上那个灰色 FN 方块只是还原实物，不会亮。

LOGO 键（蓝色箭头）
--------------------
LOGO 走的是 usage 105（byte4 的 bit7），不在按钮位图里，所以以前一直
被当成 FN。现在键位表已经改正，按 LOGO = 虚拟手柄的 LOGO 键。

游戏里出现两个手柄（原神等）
----------------------------
游戏会同时看到「物理北通」和「虚拟 Xbox」这两把，所以会显示两个手柄。
解决：主界面右上角点「屏蔽物理手柄」，游戏里就只剩虚拟 Xbox 那一把了。

原理（v1.0.13 起）：HidHide 内核过滤驱动（跟 ViGEmBus 同一家出品）。
点屏蔽时把物理北通加进 HidHide 黑名单，内核直接对游戏隐瞒这把设备；
映射器自己在 HidHide 白名单里，照常读手柄。映射跑着也能随时开关。

第一次点会弹 UAC 帮你装 HidHide（目录里附带 HidHide_x64.exe），
装完自动屏蔽。屏蔽状态由驱动记着，重启映射器也在。
取消屏蔽：再点一下同一个按钮。

几个实测细节（v1.0.13）：
· 程序会先把物理手柄的句柄攥在手里再去隐藏。HidHide 不会收回已经打开的
  句柄，所以就算白名单没生效，映射照样读得到物理手柄 —— 屏蔽一定管用。
· 换 USB 口插手柄，设备实例路径会变、老的黑名单条目就失效。每次启动映射
  会自动把当前这把补进黑名单，换口不用管。
· 手柄拔掉/休眠时也能解除屏蔽（靠记下来的实例路径），不会出现按钮卡在
  「已屏蔽」又点不动的情况。
· 屏蔽期间停止映射不会放开手柄句柄，重开直接接着用。

屏蔽名单管理（v1.0.22 新增，替代官方 HidHide Configuration Client）
----------------------------
官方那个 HidHideClient 不用再单独开了，映射器里就有完整的名单管理：

打开方式（二选一）：
· 主界面导航「工具箱」→「🛡 设备屏蔽（HidHide）」
· 主界面右上角「屏蔽物理手柄」旁边的「⚙ 名单」

能做的事：
· 总开关：HidHide 隐身功能整体启用/停用（黑名单只在启用时生效）
· 隐藏的设备（黑名单）：看/加/删被隐身的设备。● 表示现在插着，
  ○ 是记着但没插的旧实例（换 USB 口留下的，不碍事，想清就删）
· 应用白名单：看得见被隐藏设备的程序。映射器和向导必须在内，
  不然屏蔽后自己就读不到手柄了。「加程序…」可以给别的工具
  （比如北通官方驱动）放行
· 「手动加…」会列出本机所有 HID 设备，可以隐藏任意设备
  （不只手柄 —— 别乱藏键鼠，藏了它们游戏里就找不到了）
· 底部「官方客户端」按钮：想用原版 HidHideClient 时一键打开

注意：名单里有中文路径的条目会显示成乱码或被截断，这是 HidHide
CLI 自己的显示 bug，功能不受影响。删的时候按文件名认就行。

震动（新）
---------
游戏发出的 XInput 震动指令会先到虚拟 Xbox 手柄，程序再把它转写到物理手柄上。
注意物理手柄的游戏接口（0x01/0x05）没有输出报告，只有那个 64 字节的厂商私有
接口（0xFF00）能往外发东西，震动命令只能走这里。

厂商没公开命令格式，所以有三个工具来对付它：

【震动强度滑块】右侧「震动强度」，最高 300%。嫌游戏里震得太轻就往上拉，
调完点「保存键位」。

【试震一下】连震三下：先单独大马达 → 再单独小马达 → 最后两个一起，
用来判断哪个马达在响。（开了合并模式就只震两下，因为没法分左右了）

【合并模式】（v1.0.16 起，默认开着）
「四个马达合并成一个震动（不分左右 / 扳机）」—— 反正都是震动。
勾上之后：不管游戏要震大马达还是小马达、要不要震扳机，程序都拿
「信号里最大的那个强度」写进所有已配置的马达字节，四个马达一起响。
好处是只用一条已验证能震的命令就能让手柄震起来，不用挨个扫右柄和扳机；
代价是分不出左右了（本来右柄那颗也感觉不太到）。
想继续分开调，把勾去掉，「扫命令」按钮就又能用了。

【四个马达单独配置】（v1.0.14 起）
这把有四套马达：左柄（大）、右柄（小）、左扳机、右扳机 —— 官方 GO柄
app 里就是这么分的。「震动」区有一排「单马达」按钮：左柄 / 右柄 /
左扳机 / 右扳机，点哪个哪个单独震 0.9 秒。按钮发灰带「?」= 这个马达的
命令还没找出来，点了不会震。

协议是厂商私有的，没公开也没法抓包，只能穷举。点「扫命令」打开扫描器：
选目标马达 → 开始 → 程序一条条发命令（命令头 × 强度字节位置，每条 0.9
秒），**感觉到目标马达在震就立刻点「有感，就它了」**，这条就存进
keymap.json，以后这个马达能单独控制了。

· 左柄大马达已确认可用：命令头 0x08，强度写在第 3 字节，走 WriteFile
· 右柄 / 扳机默认没配，得自己扫出来
· 扫不出来有两种可能：这个马达压根没装，或者得走 SET_REPORT 通道
  （扫描器里可以选「两种通道都试」，时间翻倍）
· 扫右柄时会自动把当前能震的那条命令一起固化，不会把左柄弄失效
· XInput 只有大/小两路信号，扳机马达游戏里发不出来；想让扳机跟着震就
  勾「扳机马达跟着手柄一起震」

【🧪 震动实验室】左侧导航里，专门用来找这把能震的那条命令：
  1. 「▶ 开始扫描」：程序挨个发 58 条候选命令，感觉到震就按空格记下来
     （也能用「✕ 删选中」删记错的，「🗑 清空全部」重来）
  2. 「🏆 最强对决」：把记下来的两两对比，先震 A 再震 B，你选哪个更猛，
     几轮自动决出冠军
  3. 冠军会自动写进配置（界面下方会显示用的是哪条命令），
     记得点「保存键位」

候选是「发送通道 × 命令头 × 字节位置 × 强度值」的组合：SET_REPORT（控制通道，
Linux 里北通官方驱动 hid-betopff.c 就是这么发的）和 WriteFile（中断端点）。
这把定制版实测只有命令头 0x08 有效，大马达在第 3 字节，小马达（第 4 字节）
单独拉满没反应，大概率只有一路马达在响——那是硬件层面，软件救不了。

还有个「娱乐模式」按钮：让手柄一直震着玩，再点一次停。

界面上那行「游戏震动 → 大马达 xx · 小马达 xx」是诊断用的：有数字跳动说明
游戏确实发了震动、程序也在转发；显示红色「通道没开」就是转不出去。

这把定制版实测切不进 PC360(XInput) 模式（按官方说明操作后设备枚举毫无变化，
大概率没做 PC360 固件），所以只能这样转发。转发过来的强度由游戏决定，
可能比原生 XInput 弱一点。

托盘图标（新）
-------------
程序启动后右下角会出现一个红色圆点图标。双击 = 打开主界面，右键看菜单：

  显示主界面      把藏起来的窗口调出来
  启动/停止映射   不用开窗口也能开关映射
  ⏰ 震动闹钟     打开闹钟设置（前面打勾 = 闹钟开着）
  试震一下        不用开窗口也能试震
  🔄 检查更新     看看有没有新版本
  退出程序        真正退出（关窗口只是藏起来）

关窗口 = 藏到托盘，程序还在后台跑（闹钟照样会响）。想让它真的退出就走右键菜单。

震动闹钟（新）
-------------
左侧「⏰ 震动闹钟」：到设定时间手柄会一直震，按手柄上任意一个键就停。

  1. 调好时间（24 小时制），点「启用闹钟」
  2. 勾「每天重复响」= 每天都响；不勾 = 只响一次，响完自动关
  3. 「震动强度」跟主界面那个滑块一样，最高 300%
  4. 「铃声」下拉里选震动的节奏，下面一行小字会说明这个铃声什么感觉：

       连续猛震   一直震到停，最不容易睡过头
       急促脉冲   震 0.45 秒停 0.18 秒，最有节奏感
       心跳       咚咚…咚咚…，像有人在拍你
       渐强       每 3 秒从 25% 爬到满，越拖越猛
       三连滴     滴-滴-滴，停一下再来
       波浪       2 秒一个来回，强弱平滑起伏
       警笛       短促连击，间隔由快到慢
       SOS 摩斯   …---…，好玩但费马达

     选完点「试听铃声」会用这个节奏震 5 秒，再点按钮（或换铃声、关窗）立刻停。
  5. 「立即响」= 不等设定时间，立刻按完整流程响一次，用来验证整条链路通不通
     （响起来后按手柄任意键停，最多 2 分钟）
  6. 响了之后：按手柄任意键 / 扳机 / 大幅推摇杆都能停；
     没人管的话最多震 2 分钟自动停

  注意：设的时间如果今天已经过了，闹钟会排到明天，倒计时前面会显示「明天」。
  想立刻验证就点「立即响」。

闹钟不需要启动映射也能工作——它自己开一路 HID 读按键、一路发震动。
改完设置会立刻存进 keymap.json，关了程序下次开还在。

📱 手机通知 → 手柄震动（新手教程）
---------------------------------
手机上来了消息（微信、QQ、短信……），手柄就震一下。打游戏不用看手机也知道有事。

【一句话原理】
本机在局域网里起一个极简 HTTP 服务（默认端口 9595）。手机把通知变成一次
网页请求打过来，程序收到就按选好的铃声震一下。手机和电脑要连同一个 WiFi。

＝＝＝ 第 1 步：电脑端开起来 ＝＝＝

  1. 打开映射器，左侧导航点「📱 手机通知」
  2. 先点「放行防火墙」（弹 UAC 点「是」）——
     这步不做手机必定连不上，建议一上来就点
  3. 勾「开启（局域网接收手机通知）」
  4. 界面上会列出本机地址，挑那个跟你路由器同段的
     （比如 http://192.168.1.13:9595 ），点「复制地址」
     注意：如果列了 192.168.8.1、192.168.190.1 这类，那是虚拟机/热点
     的虚拟网卡，手机连不上，别选它们
  5. 点「测试震动」—— 手柄应该震一下，确认震动通路没问题

＝＝＝ 第 2 步：先手动验证一次（别急着配自动）＝＝＝

  手机连同一个 WiFi，浏览器打开刚才那个地址（不加 /notify），
  页面上有个「震一下」按钮。点了手柄震，说明整条链路通了，
  再去配自动触发。直接跳到第 3 步结果连不上，就分不清是手机的问题还是电脑的。

＝＝＝ 第 3 步：让它自动触发 ＝＝＝

【安卓】装 MacroDroid（免费，应用商店就有，国产机也能装）：
  1. 打开 MacroDroid → 右下角「添加宏」
  2. 触发器：点「+」→ 应用程序 →「通知收到」
     → 选要监听的应用（想全监听就勾「所有应用」）
     注意：MacroDroid 要开「通知读取权限」，系统会跳设置，允许它
  3. 动作：点「+」→ 应用程序 →「Web 服务」→「HTTP 请求」
       · 请求方式选 GET
       · URL 填 `http://192.168.1.13:9595/notify`
       想看清是谁来的，加参数：
         `/notify?app=[notification_app]&title=[notification_title]`
       （MacroDroid 里点输入框右边的「魔法文本」能插入通知的 App 名和标题；
        先不带参数试通了，再回来加）
  4. 约束：不用设，留空
  5. 给宏起个名（比如「手柄震」），右上角保存
  6. 点宏名字手动「测试动作」，手柄震就成功

  嫌装 app 麻烦：国产手机自带的「场景自动化 / 智慧生活」有些也支持
  「发送 HTTP 请求」，填同一个地址即可，各家位置不同。
  Tasker + AutoNotification 同理。

【苹果】说明白点：iOS 的快捷指令自动化里**没有「收到任意通知」这个触发器**，
  所以微信、QQ 这类第三方通知没法像安卓那样全自动转发。能用的替代：
  · 短信 / iMessage：快捷指令 → 自动化 → 创建个人自动化 →「收到信息时」
    → 添加操作「获取 URL 内容」→ 填 `http://192.168.1.13:9595/notify`
  · 邮件：同理选「收到邮件时」
  · 想覆盖所有 App：得装第三方（如 Pushcut，可把本地通知转成 webhook），
    免费版有限制
  · 最省事还是用第 2 步那个网页按钮，手动点一下

＝＝＝ 可以调的东西 ＝＝＝

  震动样式 / 强度 / 持续秒数   通知来了怎么震，默认「三连滴」1.2 秒，
                              样式跟闹钟那节列出的那几种一样
  过滤                        默认「全部通知」；
                              「只震这些」填关键词（逗号分隔，如 `微信,电话`）
                              「屏蔽这些」则反过来
  冷却                        同一个 app 多少秒内只震一次（默认 3 秒），
                              防群消息把马达轰成震动棒
  口令                        填了之后手机请求必须带 `?token=你填的`，
                              防止同网的人恶搞你
  端口                        默认 9595，被别的软件占了就换一个，
                              改完自动重启监听
  最近收到                    列出每条通知的处理结果：
                              已震动 / 冷却中 / 被屏蔽 / 令牌不对
                              排查时先看这一栏

＝＝＝ 连不上怎么办（按顺序查）＝＝＝

  1. 防火墙：点窗口里的「放行防火墙」（会弹 UAC，点「是」）。
     手动也行：Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙
     → 勾上本程序（专用网络）
  2. 网络：手机和电脑必须在同一个 WiFi，不能是手机流量，
     也不能是路由器的「访客网络」（很多路由器访客网开了 AP 隔离，设备之间不通）
  3. 地址选错：别用 127.0.0.1（那是电脑自己），也别用虚拟网卡的 IP。
     手机要填的是 192.168.x.x 那个
  4. 电脑休眠/程序关了：服务跟着程序走，程序退出或电脑睡了就不响
  5. 手机端的省电限制：国产机会杀后台，把 MacroDroid 加进
     「自启动 / 后台保护 / 电池优化白名单」，否则过一会儿就不触发了
  6. IP 变了：路由器重启后电脑 IP 可能变，回来看看界面上显示的地址

注意：这个功能默认关着，要自己勾开；开着的时候程序会监听局域网端口。
不需要启动映射也能震（它会自己开一路 HID）。

键位识别向导的等待时间
----------------------
向导顶部有个「每键等待」输入框，默认 10 秒：每提示一个键，会给足 10 秒时间，
大倒计时带进度条，来不及就点「再等一会」。10 秒内没按会自动跳过这个键。
摇杆和扳机那两步推得到位会提前结束，不用干等。
